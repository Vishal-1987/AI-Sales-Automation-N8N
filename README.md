# AI Sales Automation System

## Project Overview

An AI-powered sales automation system built with n8n that automates the complete lead management process from lead capture to qualification, routing, email follow-up, CRM updates, and lead information querying.

## Project Objective

The objective of this project is to automate the sales lead management process and reduce manual work using n8n, AI/LLM, Airtable/Google Sheets, Gmail, and other integrations.

## Main Features

- Lead capture through form
- Lead data cleaning and validation
- Duplicate lead detection
- Lead storage in CRM
- AI-powered lead qualification
- Lead scoring
- Hot/Warm/Cold lead classification
- Personalized email generation
- Automated CRM updates
- AI Agent for querying lead information
- Error handling and notifications
- Cloud-based n8n deployment

## Workflows

### 1. AI Sales Automation System

Lead flow:

Form Submission → Data Cleaning & Validation → Duplicate Check → AI Lead Qualification → Lead Routing → Personalized Email → CRM Update

### 2. User Lead Query Agent

This AI Agent allows users to query stored lead information using natural language.

### 3. Error Handling Workflow

This workflow captures workflow errors, stores error information, and sends notifications.
